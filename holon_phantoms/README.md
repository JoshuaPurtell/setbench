# Holon Phantoms

This directory is the source-of-truth benchmark family scaffold for Holon Phantoms.

## Status

Holon Phantoms currently has:

- placeholder gold files copied from `setbench-engine-core`
- matching stub files
- a curriculum manifest for `0pct`, `30pct`, and `80pct`

Holon Phantoms is blocked because the engine-core tip does not yet contain a real HP reference implementation. Until that exists, this family should be treated as structural only.
