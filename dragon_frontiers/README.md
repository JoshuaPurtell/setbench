# Dragon Frontiers

This directory is the source-of-truth benchmark family scaffold for Dragon Frontiers.

## Status

Dragon Frontiers has:

- gold files copied from `setbench-engine-core`
- a matching stub surface
- a curriculum manifest for `0pct`, `30pct`, and `80pct`

Dragon Frontiers does not yet have:

- public train fixtures
- hidden held-out fixtures
- deterministic eval runners
- export-ready task packaging

So this family is structurally scaffolded but not yet eval-ready.
